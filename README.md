# arface-watch

پایش هفتگی و خودکار قیمت صابون‌های مشابه آرفیس در ترب.

## چه کار می‌کند؟

۱. هر دوشنبه ساعت ۰۶:۰۰ به وقت تهران، با GitHub Actions اجرا می‌شود.
۲. برای هر دسته (حلزون، زغال فعال، خاک رس، لوفا، انار، پیله ابریشم، گلیسیرینه) صابون‌های مشابه در ترب را از API عمومی ترب می‌خواند؛ پایه صابون و مواد اولیه صابون‌سازی کنار گذاشته می‌شوند.
۳. ارزان‌ترین‌ها را کنار قیمت همان صابون در سایت آرفیس (arface.ir) می‌گذارد و با هفته قبل مقایسه می‌کند.
۴. نتیجه در report.md نوشته می‌شود؛ اسنپ‌شات هر هفته در data/snapshots/ و سابقه کامل قیمت‌ها در data/history.csv می‌ماند تا روند قیمت بازار در طول زمان مشخص باشد.

## نکته

این مخزن عمومی است و فقط داده‌های عمومی بازار (قیمت و نام فروشگاه در ترب) و قیمت‌های عمومی سایت آرفیس را نگه می‌دارد؛ هیچ داده داخلی یا خصوصی در آن نیست.
